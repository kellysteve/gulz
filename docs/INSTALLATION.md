# Installation centre

The public website groups installation instructions by target environment:

- Android / Termux
- Linux distributions
- macOS (Apple Silicon and Intel)
- Windows
- VPS and SSH-connected servers
- Developer installation

Each guide must include supported versions and architectures, prerequisites, the install method, integrity verification, first-run setup, update and uninstall instructions, and troubleshooting.

**Current status:** guides describe the intended user experience only. No GULZ installer or public release artifact has been published yet. Do not copy illustrative commands into production documentation.
